# Moch. Alfan Miftachul Huda — Portfolio

Static portfolio built with HTML, CSS, and vanilla JavaScript. It is ready for GitHub Pages because the site uses relative local assets and no build step.

## Local preview

```bash
python -m http.server 4173
```

Open `http://localhost:4173`.

## GitHub Pages

1. Create or use the public repository `alternatif-omg.github.io`.
2. Push this folder to the `main` branch.
3. For a user-site repository, GitHub Pages will serve the root at `https://alternatif-omg.github.io`.
4. If using another repository name, open **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/root`.
